Introducción

Wissive es una librería de JavaScript/TypeScript vanilla — sin framework, sin dependencias de runtime obligatorias — que renderiza 14 personajes tipo blob con diseño propio. Cada uno tiene 24 expresiones repartidas en 4 estados de interacción, interpoladas con un resorte amortiguado en vez de transition lineal de CSS, así que el movimiento entre expresiones se siente orgánico.

No es un set de íconos: es un motor de expresión con un catálogo ya diseñado, pensado para tener, en dos líneas de código, un emoji que reacciona de verdad al mouse, al teclado y al touch.

Instalación

Vía pnpm, para usar con un bundler:

pnpm add wissive
import { createEmoji } from 'wissive';

createEmoji('mochi', { target: document.querySelector('#slot') });

O vía CDN, sin instalar nada:

<script src="https://cdn.jsdelivr.net/npm/wissive/dist/wissive.umd.js"></script>
<div id="slot"></div>
<script>
  Wissive.createEmoji('mochi', { target: document.querySelector('#slot') });
</script>

El paquete todavía no está publicado en npm — estos comandos funcionarán una vez publicado (ver Roadmap).

Uso básico

Tres formas comunes de usar createEmoji(), con el código real de cada una.

Emoji básico 
createEmoji('mochi', { target, size: 100 });
Control programático 
const emoji = createEmoji('mochi', { target });

emoji.setEmotion('happy');
emoji.setEmotion('sad');
emoji.bounce();
Solo decorativo (sin listeners) 
// No reacciona a hover/click/near; solo su animación de personalidad
createEmoji('nima', { target, interactive: false });

Estados de interacción

Cada estado dispara un pool de variantes; se sortea una evitando repetir la anterior.

EstadoDisparadorDescripción
idleSin interacciónReposo, respiración lenta.
nearCursor se acerca (radio configurable)El emoji "nota" que algo se acerca.
hovermouseenter / mouseleaveCursor directamente encima.
clickmousedown/up, touchstart, Enter/EspacioInteracción directa.
 
emoji.setEmotion('hover'); // control programático, sin mouse
emoji.destroy();           // limpieza: RAF + listeners + timers

Sonido (opcional)

Integración opcional con Cuelume — peer dependency, nunca obligatoria. Se detecta en tiempo de ejecución (import dinámico); si no está instalada, la librería funciona igual, en silencio, sin errores en consola. 

createEmoji('mochi', { target, sound: true });  // por instancia
emoji.setSound(false);                          // togglear en runtime

Accesibilidad

role="img" + aria-label dinámico según la emoción y el estado actual. Navegable por teclado (tabindex, Enter/Espacio equivalen a click). Respeta prefers-reduced-motion del sistema operativo. Contraste trazo/relleno verificado ≥3:1 (WCAG) en los 14 emojis.

Integración con frameworks

Wrappers oficiales para React, Vue y Astro (wissive/react, wissive/vue, wissive/astro) — en React/Vue empaquetan el patrón createEmoji() + destroy() de siempre; en Astro no resuelven timing (no hace falta), ahorran repetir el <script> si usás el emoji en varias páginas. Elegí uno — el bloque de abajo lo recuerda.

Ejemplos completos en examples/.

Roadmap

Lo que falta para el release v1.0 (detalle completo en requerimientos.md):

  • Publicar en npm y probar el UMD vía CDN real.
  • Opción global (no solo por-instancia) para apagar todo el sonido.
  • Auditoría de accesibilidad con axe/Lighthouse en navegador real.
  • Test cruzado de navegadores + prueba de carga con 50 instancias simultáneas.
  • Decisión explícita sobre near/hover en dispositivos táctiles.
